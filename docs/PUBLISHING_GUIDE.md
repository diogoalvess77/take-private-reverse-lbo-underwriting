### Project name
`Take-Private Reverse LBO & Probabilistic Underwriting | Project Redwood`

### Description
Built a fictional private equity take-private case study combining an Excel LBO model, reverse-LBO bid ceiling and Python probabilistic underwriting engine. Modelled transaction financing, operating performance, debt paydown and sponsor returns; then solved the maximum entry valuation consistent with a 25% gross IRR hurdle. Extended the analysis across 10,000 correlated synthetic deal paths to estimate return distributions, downside credit risk and probability-based bid ceilings. The case supports an 8.1x deterministic maximum bid versus an 8.5x seller ask, with a 32.9% simulated probability of clearing the 25% IRR hurdle at the ask.
