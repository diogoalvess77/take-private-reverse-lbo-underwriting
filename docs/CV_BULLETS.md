# CV Bullets - Project Redwood

## More concise
- Built a fictional take-private LBO and reverse LBO model, solving the maximum underwritable entry multiple against sponsor IRR and MOIC hurdles.
- Developed a Python risk engine running 10,000 synthetic deal paths to estimate return distributions, downside risk and risk-adjusted bid ceilings.

## More technical
- Modelled a take-private transaction from sources & uses through operating forecast, debt paydown, exit value, sponsor IRR/MOIC and reverse LBO bid ceiling.
- Used Python to simulate 10,000 correlated deal paths, quantify probability of meeting a 25% IRR hurdle and test risk-adjusted bid discipline across entry multiples.
