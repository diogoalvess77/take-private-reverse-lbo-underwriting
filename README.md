# Take-Private Reverse LBO & Probabilistic Underwriting | Project Redwood

A fictional private-equity take-private case study combining an Excel LBO model, reverse-LBO bid discipline, a hurdle solver and probabilistic underwriting.

## What is included

- **Excel LBO model** with sources & uses, operating case, debt paydown and sponsor returns.
- **Reverse LBO** that solves the maximum underwritable entry multiple against sponsor hurdles.
- **Python risk engine** with 10,000 synthetic correlated deal paths.
- **Interactive underwriting dashboard** with adjustable entry/exit multiples, target IRR, rates, growth, margins and leverage.
- **Automated tests** and a GitHub Actions workflow.
- **Investment Committee Overview** PDF.

## Headline baseline outputs

- Seller ask: **8.5x EBITDA**
- Base-case gross IRR / MOIC: **22.3% / 2.74x**
- Deterministic max bid: **~8.1x**
- P(IRR >= 25%) at ask: **32.9%**
- 50% probability bid ceiling: **8.0x**
- 75% probability bid ceiling: **7.5x**

## Explore the project

- `Take_Private_Reverse_LBO_Probabilistic_Underwriting_Model.xlsx` — Excel model
- `Project_Redwood_Investment_Committee_Overview.pdf` — presentation-ready overview
- `outputs/interactive_ic_dashboard.html` — interactive browser sensitivity dashboard
- `run_risk_simulation.py` — regenerates Python model outputs
- `src/risk_engine.py` — underwriting logic
- `tests/test_risk_engine.py` — validation tests

The interactive dashboard is an educational client-side sensitivity tool. The exported baseline results and official model outputs are generated by the Python engine.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_risk_simulation.py --paths 10000 --seed 77
python -m pytest -q
```
